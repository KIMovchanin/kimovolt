# KIMOVOLT LAB

> **Не просто изучай электронику. Заставь её работать.**  
> *Don't just learn electronics. Make it work.*

**KIMOVOLT LAB** — интерактивная образовательная веб-платформа для изучения электроники: от первого светодиода и закона Ома до диагностики неисправностей, цифровой логики, работы с виртуальными приборами и перехода к реальным устройствам на Arduino UNO, ESP32-C3 и ESP32-S3.

---

## Ключевые возможности (v1.0)

- **Реальный математический симулятор цепей (`@kimovolt/simulation`):**
  - Линейные DC-цепи произвольной топологии через **Modified Nodal Analysis (MNA)** в Web Worker (не блокирует 60 FPS UI).
  - Кусочно-линейная модель светодиодов и диодов (`Vf` + `0.5 Ω` в прямом направлении, `10 MΩ` в обратном), расчёт токов ветвей, падений напряжений, тепловой мощности и выявление перегрузок/КЗ/переполюсовки.
  - Симуляция контактных шин макетной платы (Breadboard View) и классической принципиальной схемы (Schematic View).
  - Булев DAG-решатель логических элементов (`NOT`, `AND`, `OR`, `XOR`, `NAND`, `NOR`) с проверкой полной таблицы истинности.
  - Генератор сигналов и расчётчик RC-кривых для виртуального осциллографа.
- **Интерактивный редактор и приборы (`@kimovolt/frontend`):**
  - Режимы `X-Ray`, `Показать ток` (с пояснением условности направления), `Показать напряжение`, `Показать мощность`, `Что если?` (сравнение «До/После») и диагностическая консоль.
  - Виртуальный мультиметр (`V⎓`, `mA⎓`, `Ω`, прозвонка `♪`) с защитой от параллельного включения амперметра.
  - Осциллограф (`Time/div`, `Volt/div`, триггер, курсоры `Δt / 1/Δt / Vpp`).
  - Клавиатурное управление схемой (`Tab`, стрелки, `Enter`, `R`, `Del`, `Ctrl+D`, `Ctrl+Z` / `Ctrl+Shift+Z`).
- **Образовательное ядро (`@kimovolt/content`):**
  - **15 интерактивных уроков** по методике *Наблюдение → Предположение → Эксперимент → Измерение → Объяснение → Применение*, включая 7-сценовый эталонный Урок 1 «Зажги первый светодиод» и два квеста («Погасший маяк», «Неизвестный сигнал»).
  - **10+ проверяемых типов упражнений** (без оценки по координатам JSON — проверка по физическим инвариантам MNA, таблицам истинности и перебору состояний кнопок).
  - Раздельные **XP** и **Mastery (0–100%)**, интервальные повторения (SRS: `4ч → 1д → 3д → 7д → 21д`), классификатор типовых заблуждений, достижения, инженерный блокнот, справочник компонентов и низковольтные проекты.
  - Гостевой режим без обязательной регистрации + бесшовная миграция прогресса и схем в аккаунт.
- **Компактный бэкенд (`backend/`):**
  - Один статический бинарник **Go 1.26** (`net/http` + `modernc.org/sqlite` без CGO в режиме WAL), Argon2id, HttpOnly-сессии, CSRF-защита, rate limiting, `robots.txt` и `sitemap.xml`.
  - Готовая кросс-компиляция с Windows на **Oracle Cloud Always Free Linux ARM64** за Caddy с автоматическим HTTPS.

## Структура репозитория

```text
kimovolt-lab/
├── simulation/   # @kimovolt/simulation — MNA, логика, осциллограф, цвет. маркировка
├── content/      # @kimovolt/content — 15 уроков, валидаторы, Mastery/SRS, i18n RU/EN
├── frontend/     # @kimovolt/frontend — React 19 + Vite + SVG/Canvas Workbench + 9 страниц
├── backend/      # Go 1.26 REST API + SQLite WAL + раздача статики и SEO
├── tests/        # Playwright E2E и визуальная проверка (desktop/tablet/mobile)
├── deploy/       # Caddyfile, systemd unit, скрипты бэкапа и обновления (ARM64)
├── scripts/      # Скрипты сборки под Windows и Linux ARM64
└── docs/         # Архитектура, разработка, деплой, ограничения симуляции, безопасность
```

## Быстрый старт (Windows / Linux)

Подробности см. в [docs/DEVELOPMENT.md](./docs/DEVELOPMENT.md).

```powershell
# 1. Установка зависимостей JS и проверка всех модульных тестов
npm.cmd install
npm.cmd run typecheck
npm.cmd test

# 2. Сборка production-фронтенда и запуск единого Go-сервера
npm.cmd run build --workspace=frontend
cd backend
go test -v ./...
go run ./cmd/server
# Приложение доступно на http://localhost:8080
```
