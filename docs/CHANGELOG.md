# Changelog — KIMOVOLT LAB

## v1.0.0 — 2026-11-19

- **Бренд и дизайн-система:** утверждено название **KIMOVOLT / KIMOVOLT LAB**, создан оригинальный геометрический логотип (K + медная дорожка + символ диода), реализованы тёмная тема *Obsidian Laboratory* и светлая тема *Blueprint Paper*, кириллическая типографика (`Unbounded`, `Golos Text`, `JetBrains Mono tabular-nums`).
- **Симулятор (`@kimovolt/simulation`):** реализованы линейный решатель MNA DC, кусочно-линейная модель LED/диодов, виртуальный мультиметр с защитой шунта, внутренние контактные шины макетной платы, булев DAG-решатель, генератор сигналов и RC-кривых, 4/5-полосная маркировка резисторов, безопасный импорт `.kimovolt.json`.
- **Образовательная платформа (`@kimovolt/content`):** реализованы 15 интерактивных уроков (включая 7-сценовый эталонный Урок 1 и 2 квеста), 10+ валидаторов заданий, раздельные XP и Mastery, система интервальных повторений SRS, классификатор заблуждений, достижения, инженерный блокнот, 12 статей справочника с мини-симуляторами, 6 низковольтных проектов и проверенные распиновки Arduino UNO, ESP32-C3, ESP32-S3.
- **Веб-приложение (`@kimovolt/frontend`):** реализованы главная страница с живой интерактивной схемой, карта-плата обучения, студия урока, свободная лаборатория (Schematic + Breadboard, X-Ray, Что если?, приборы), гостевой режим без регистрации, пасхалки (404, 42 Ω, волшебный дым, XY-осциллограф).
- **Бэкенд и деплой (`backend/`, `deploy/`):** реализован сервер на Go 1.26 + `modernc.org/sqlite` (WAL), Argon2id, HttpOnly-сессии, CSRF, rate limiter, SEO (`robots.txt`, `sitemap.xml`), кросс-сборка под Linux ARM64 и конфиги для Oracle Always Free.
